# epHOLD OS — Official Website

**epHOLD OS** is a lightweight, sovereignty-focused operating system designed to run decentralized infrastructure on minimal hardware.

🌐 Live site: http://hold.edgarpaula.org

---

## 🧠 About epHOLD

The name **epHOLD** stands for **Holder Edgar Paula** — a statement of ownership and philosophy.

To be a *holder* is not only about keeping Bitcoin.
It is about maintaining control over your data, your keys, and your infrastructure.

epHOLD OS is built around this principle:
**run your own node, control your own network, own your digital presence.**

---

## 🎯 Purpose

The goal of epHOLD OS is to make digital sovereignty accessible to anyone.

With a simple setup, users can run:

* A lightweight Bitcoin node (Floresta-based)
* A Lightning Network node (Neutrino mode)
* A Nostr relay for decentralized communication

All running on:

* Old computers
* Raspberry Pi
* Low-cost VPS

---

## ⚙️ Philosophy

epHOLD follows a clear design philosophy:

* **Minimalism** → no unnecessary overhead
* **Efficiency** → optimized for low-resource environments
* **Autonomy** → no reliance on third parties
* **Privacy** → user-controlled data
* **CLI-first** → simple, powerful interface
