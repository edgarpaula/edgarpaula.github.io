// 01 — Texto institucional

O que é o epHOLD OS?

epHOLD significa Holder Edgar Paula — uma declaração de autoria, mas sobretudo de princípio. Ser um holder vai além de guardar Bitcoin: é a postura de quem não terceiriza a própria soberania. É quem mantém suas chaves, seus dados e sua infraestrutura sob controle total e permanente.

O epHOLD OS é a materialização técnica dessa filosofia. Um sistema operacional construído do zero com uma única obsessão: dar a qualquer pessoa — seja um developer experiente ou um entusiasta com um Raspberry Pi na gaveta — a capacidade de operar sua própria soberania digital sem depender de terceiros, servidores corporativos ou interfaces intermediárias.

Por que isso importa?

A infraestrutura da internet atual é centralizada por design: exchanges custodiam seus Bitcoin, relays corporativos distribuem suas mensagens, e provedores de nuvem hospedam tudo que você considera "seu". O epHOLD OS existe para inverter essa equação — transformar qualquer hardware ocioso em um nó soberano da rede.

Você não precisa de um datacenter. Precisa de um computador antigo, uma conexão de internet modesta e a decisão de ser o operador da sua própria infraestrutura.

// 02 — Arquitetura do sistema

Arquitetura Técnica

A escolha de base é Debian 12 Bookworm (minimal) — estável, com suporte longo (LTS), pacotes bem documentados, comunidade gigante e a menor pegada de disco entre as distribuições prontas para servidor. Alternativa considerada: Alpine Linux (mais leve, mas muralha de compatibilidade com Rust/Go em ARM).

Por que Floresta em vez de Bitcoin Core?

O Bitcoin Core requer o download completo da blockchain (~600 GB em 2025). O Floresta é um cliente Bitcoin em Rust que implementa Utreexo — uma estrutura de dados compacta que permite verificar transações sem armazenar o UTXO set completo. Resultado: sincronização em horas, não semanas, e consumo de disco na faixa de poucos gigabytes.

Por que LND em modo Neutrino?

O LND (Lightning Network Daemon) em modo Neutrino usa compact block filters (BIP 157/158) para verificar transações sem ter um full node local. Integrado ao Floresta, forma um stack Bitcoin/Lightning completo e leve que sincroniza em minutos em hardware modesto.

Gerenciador de serviços: systemd vs OpenRC

Para o epHOLD OS baseado em Debian, usamos systemd como gerenciador de serviços por ser padrão na distribuição-base, ter melhor integração com journald (logs centralizados), e amplamente documentado. O Python não reinventa o gerenciamento de processos — ele orquestra o systemd via subprocessos, adicionando health checks, notificações e lógica de retry customizada.

2. Leitura de configuração — core/config.py

core/config.py
"""
epHOLD OS — Módulo de Configuração
Lê e valida o arquivo epHOLD.conf central.
"""

import configparser
import os
from pathlib import Path

CONFIG_PATH = Path("/opt/ephold/config/epHOLD.conf")


class EPHoldConfig:
    def __init__(self, path: Path = CONFIG_PATH):
        self.path = path
        self._cfg = configparser.ConfigParser()
        self._load()

    def _load(self):
        if not self.path.exists():
            raise FileNotFoundError(
                f"Config não encontrado: {self.path}\n"
                "Execute: ephold init"
            )
        self._cfg.read(self.path)

    def get(self, section: str, key: str, fallback=None):
        return self._cfg.get(section, key, fallback=fallback)

    def getbool(self, section: str, key: str, fallback=False):
        return self._cfg.getboolean(section, key, fallback=fallback)

    def getint(self, section: str, key: str, fallback=0):
        return self._cfg.getint(section, key, fallback=fallback)

    @property
    def services_enabled(self) -> list[str]:
        """Retorna lista de serviços habilitados no config."""
        enabled = []
        for section in ["bitcoin", "lightning", "nostr"]:
            if self.getbool(section, "enabled"):
                enabled.append(self.get(section, "service_name"))
        return enabled


# Instância global
config = EPHoldConfig()

3. Monitor de serviços — core/monitor.py

core/monitor.py
"""
epHOLD OS — Monitor de Serviços
Verifica saúde e reinicia serviços com falha via systemctl.
"""

import subprocess
import logging
import time
from dataclasses import dataclass
from enum import Enum

logger = logging.getLogger("ephold.monitor")


class ServiceState(Enum):
    ACTIVE   = "active"
    INACTIVE = "inactive"
    FAILED   = "failed"
    UNKNOWN  = "unknown"


@dataclass
class ServiceStatus:
    name:  str
    state: ServiceState
    pid:   str = ""
    uptime: str = ""


def check_service(service_name: str) -> ServiceStatus:
    """Consulta estado de um serviço systemd."""
    try:
        result = subprocess.run(
            ["systemctl", "is-active", service_name],
            capture_output=True, text=True, timeout=5
        )
        raw = result.stdout.strip()
        state = ServiceState(raw) if raw in [s.value for s in ServiceState] \
                else ServiceState.UNKNOWN
        return ServiceStatus(name=service_name, state=state)
    except subprocess.TimeoutExpired:
        logger.warning(f"Timeout ao verificar {service_name}")
        return ServiceStatus(name=service_name, state=ServiceState.UNKNOWN)


def restart_service(service_name: str) -> bool:
    """Reinicia um serviço systemd. Retorna True se bem-sucedido."""
    logger.warning(f"⚠ Reiniciando serviço: {service_name}")
    try:
        result = subprocess.run(
            ["systemctl", "restart", service_name],
            capture_output=True, text=True, timeout=30
        )
        success = result.returncode == 0
        if success:
            logger.info(f"✓ {service_name} reiniciado com sucesso")
        else:
            logger.error(f"✗ Falha ao reiniciar {service_name}: {result.stderr}")
        return success
    except subprocess.TimeoutExpired:
        logger.error(f"Timeout ao reiniciar {service_name}")
        return False


def monitor_loop(services: list[str], interval: int = 30, restart_delay: int = 30):
    """
    Loop principal de monitoramento.
    Verifica cada serviço e reinicia automaticamente em caso de falha.
    """
    logger.info(f"Monitor iniciado — serviços: {services}")

    while True:
        for svc in services:
            status = check_service(svc)

            if status.state == ServiceState.ACTIVE:
                logger.debug(f"[OK] {svc}")

            elif status.state in (ServiceState.FAILED, ServiceState.INACTIVE):
                logger.error(f"[FALHA] {svc} está {status.state.value}")
                time.sleep(restart_delay)
                restart_service(svc)

            else:
                logger.warning(f"[?] {svc} estado desconhecido")

        time.sleep(interval)

4. Daemon principal — core/daemon.py

core/daemon.py
"""
epHOLD OS — Daemon principal
Inicializa logging, lê config e inicia o monitor em thread separada.
"""

import logging
import threading
import signal
import sys
from pathlib import Path
from core.config import config
from core.monitor import monitor_loop


def setup_logging():
    log_dir = Path(config.get("general", "log_dir", fallback="/opt/ephold/logs"))
    log_dir.mkdir(parents=True, exist_ok=True)
    log_level = config.get("general", "log_level", fallback="INFO")

    logging.basicConfig(
        level=getattr(logging, log_level, logging.INFO),
        format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
        handlers=[
            logging.StreamHandler(sys.stdout),
            logging.FileHandler(log_dir / "ephold.log"),
        ]
    )


def handle_signal(signum, frame):
    logging.getLogger("ephold").info("Sinal recebido — encerrando daemon...")
    sys.exit(0)


def start_daemon():
    setup_logging()
    logger = logging.getLogger("ephold")
    logger.info("═══ epHOLD OS Daemon iniciando ═══")

    signal.signal(signal.SIGTERM, handle_signal)
    signal.signal(signal.SIGINT, handle_signal)

    services = config.services_enabled
    interval = config.getint("general", "monitor_interval", fallback=30)
    restart_delay = config.getint("general", "restart_delay", fallback=30)

    monitor_thread = threading.Thread(
        target=monitor_loop,
        args=(services, interval, restart_delay),
        daemon=True,
        name="ephold-monitor"
    )
    monitor_thread.start()
    monitor_thread.join()


if __name__ == "__main__":
    start_daemon()

5. CLI — cli/cli.py

cli/cli.py
"""
epHOLD OS — Interface de Linha de Comando
Uso: ephold <comando> [opções]
"""

import argparse
import subprocess
import sys
from core.config import config
from core.monitor import check_service, ServiceState


BANNER = """
  ___  _  _  _  _  ___  _    ___     ___  ___
 | __|| \| || || || __|| |  |   \   / _ \/ __|
 | _| | .` || __ || _| | |__| |) | | (_) \__ \\
 |___||_|\_||_||_||___||____|___/   \___/|___/
 ─────────────────────────────────────────────
 Soberania Digital · hold.edgarpaula.org
"""


def cmd_status(args):
    """Mostra status de todos os serviços."""
    print(BANNER)
    services = config.services_enabled
    for svc in services:
        st = check_service(svc)
        icon = "✓" if st.state == ServiceState.ACTIVE else "✗"
        color = "\033[92m" if st.state == ServiceState.ACTIVE else "\033[91m"
        reset = "\033[0m"
        print(f"  {color}{icon} {svc:<20} {st.state.value}{reset}")


def cmd_start(args):
    """Inicia um ou todos os serviços."""
    targets = [args.service] if args.service else config.services_enabled
    for svc in targets:
        print(f"▶ Iniciando {svc}...")
        subprocess.run(["systemctl", "start", svc])


def cmd_stop(args):
    """Para um ou todos os serviços."""
    targets = [args.service] if args.service else config.services_enabled
    for svc in targets:
        print(f"■ Parando {svc}...")
        subprocess.run(["systemctl", "stop", svc])


def cmd_logs(args):
    """Mostra logs de um serviço."""
    svc = args.service or "ephold-daemon"
    lines = args.lines or 50
    subprocess.run(["journalctl", "-u", svc, "-n", str(lines), "--no-pager"])


def cmd_info(args):
    """Mostra informações do node."""
    node = config.get("general", "node_name", fallback="epHOLD")
    net  = config.get("bitcoin", "network", fallback="mainnet")
    print(f"\n  Node:    {node}")
    print(f"  Rede:    {net}")
    print(f"  Config:  /opt/ephold/config/epHOLD.conf\n")


def main():
    parser = argparse.ArgumentParser(
        prog="ephold",
        description="epHOLD OS — Soberania Digital CLI"
    )
    sub = parser.add_subparsers(dest="command")

    # status
    sub.add_parser("status", help="Status dos serviços")

    # start
    p_start = sub.add_parser("start", help="Iniciar serviço(s)")
    p_start.add_argument("service", nargs="?", help="Nome do serviço (omita para todos)")

    # stop
    p_stop = sub.add_parser("stop", help="Parar serviço(s)")
    p_stop.add_argument("service", nargs="?")

    # logs
    p_logs = sub.add_parser("logs", help="Ver logs")
    p_logs.add_argument("service", nargs="?")
    p_logs.add_argument("-n", "--lines", type=int, default=50)

    # info
    sub.add_parser("info", help="Informações do node")

    args = parser.parse_args()

    handlers = {
        "status": cmd_status,
        "start":  cmd_start,
        "stop":   cmd_stop,
        "logs":   cmd_logs,
        "info":   cmd_info,
    }

    handler = handlers.get(args.command)
    if handler:
        handler(args)
    else:
        parser.print_help()


if __name__ == "__main__":
    main()

O MVP do epHOLD OS deve provar um conceito simples: em uma tarde, qualquer developer pode ter um node Bitcoin + Lightning + Nostr rodando em seu hardware. A seguir, o roteiro passo a passo.

01
Preparar a base Debian

Instalar Debian 12 minimal (sem GUI). Criar usuário dedicado ephold sem root. Configurar SSH com chave, desabilitar autenticação por senha. Aplicar ufw com regras mínimas.

Debian 12 ufw SSH keys

Instalar Floresta (Bitcoin node)

Compilar o Floresta via cargo install floresta-cli ou usar o binário pré-compilado do release. Configurar o arquivo bitcoin.toml com modo Utreexo e rede desejada. Criar o floresta.service no systemd.

Rust/Cargo Utreexo systemd
03

Baixar binário LND para a arquitetura alvo. Configurar lnd.conf com bitcoin.node=neutrino apontando para o Floresta local. Gerar seed (24 palavras), armazenar com criptografia. Criar lnd.service.

Instalar nostr-rs-relay

Compilar via Cargo ou usar binário. Configurar config.toml com limites de rate, whitelist/blacklist de pubkeys e persistência SQLite. Criar nostr-relay.service.

Clonar o repositório do epHOLD OS em /opt/ephold/. Instalar dependências via pip install -r requirements.txt. Criar symlink /usr/local/bin/ephold → /opt/ephold/cli/cli.py. Registrar o ephold-daemon.service.

// 05 — Segurança

Estratégia de Segurança

Um node Bitcoin/Lightning é infraestrutura financeira. Qualquer dado comprometido pode resultar em perda permanente de fundos. A segurança no epHOLD OS é pensada em camadas — do hardware até o backup.

🔑 Seeds e Chaves Privadas
  • Seed LND (24 palavras) nunca em texto plano no disco
  • Criptografar com age ou GPG antes de qualquer backup
  • Manter cópia física offline (papel, metal) em local seguro
  • Nunca armazenar seed em cloud ou serviço online
  • Usar lnd export-chan-backup para backup de canais
🛡️ Hardening do Sistema
  • Usuário ephold sem privilégios root
  • SSH apenas com chave pública, porta não-padrão
  • ufw: abrir apenas 8333, 9735, 7777
  • Desabilitar IPv6 se não utilizado
  • fail2ban contra brute force SSH
  • Atualizações automáticas de segurança
📦 Backup e Recuperação
  • Backup diário automático de channel.backup
  • Script de backup criptografado para USB externo
  • Testar restauração regularmente (pelo menos mensalmente)
  • Documentar procedimento de recuperação offline
  • Guardar macaroons de acesso LND com segurança

Script de backup automatizado

core/backup.py
"""
epHOLD OS — Backup automático de dados críticos.
Criptografa e comprime canal Lightning + seed (se configurado).
"""

import subprocess
import shutil
import logging
from datetime import datetime
from pathlib import Path
from core.config import config

logger = logging.getLogger("ephold.backup")

LND_DIR = Path("/opt/ephold/data/lnd")
BACKUP_DIR = Path("/opt/ephold/backups")


def backup_channel_state() -> Path:
    """Exporta o estado dos canais Lightning."""
    BACKUP_DIR.mkdir(parents=True, exist_ok=True)
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")
    dest = BACKUP_DIR / f"channel_backup_{ts}.bin"

    # Copiar channel.backup do LND
    src = LND_DIR / "data/chain/bitcoin/mainnet/channel.backup"
    if src.exists():
        shutil.copy2(src, dest)
        logger.info(f"✓ Canal backup salvo: {dest}")
        return dest
    else:
        logger.warning("channel.backup não encontrado — LND inicializado?")
        return None


def encrypt_backup(path: Path, recipient_key: str) -> Path:
    """Criptografa backup com age (https://age-encryption.org)."""
    out = path.with_suffix(".age")
    try:
        subprocess.run(
            ["age", "-r", recipient_key, "-o", str(out), str(path)],
            check=True, capture_output=True
        )
        path.unlink()  # remover versão não criptografada
        logger.info(f"✓ Backup criptografado: {out}")
        return out
    except FileNotFoundError:
        logger.warning("age não instalado — backup salvo SEM criptografia")
        return path


def run_backup():
    """Ponto de entrada do backup completo."""
    logger.info("Iniciando backup de dados críticos...")
    backup_path = backup_channel_state()

    age_key = config.get("security", "backup_key", fallback=None)
    if backup_path and age_key:
        encrypt_backup(backup_path, age_key)
